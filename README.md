# Golden Hour Invitation

Create a sophisticated, cinematic luxury wedding invitation website for: ABDELKAREEM & SHAHD IMPORTANT: Use the attached wedding invitation / venue image as the PRIMARY visual inspiration for the entire website. Do NOT use a generic modern wedding template. The website should feel like a luxury wedding invitation transformed into an elegant interactive digital experience. VISUAL IDENTITY The visual identity should be directly inspired by the reference image: - Grand romantic wedding venue - Warm candlelight - Antique champagne gold - Ivory and warm cream - Elegant architectural details - Classical arches and columns - White roses and peonies - Soft cream flowers - Muted sage and olive greenery - Delicate botanical branches - Candlelit atmosphere - Hand-painted / slightly artistic texture - Romantic old-world European elegance - Luxurious but understated - Timeless rather than trendy Use the reference image's atmosphere rather than copying it literally. The website should look like: "an antique luxury wedding invitation photographed inside a candlelit grand hall." COLOR PALETTE Primary: - warm ivory - antique champagne gold - soft cream - muted olive/sage green - very subtle warm beige Secondary: - soft blush - muted brown - warm taupe Avoid: - pure white - harsh black - saturated colors - neon colors - strong pink - purple - bright green - dark full-screen backgrounds Gold should be subtle and elegant, preferably thin-line antique champagne gold rather than shiny metallic gold. TYPOGRAPHY Use a high-fashion elegant serif typeface for: ABDELKAREEM & SHAHD and all major headings. The names must be extremely clear and readable on mobile. Use a refined serif or clean sophisticated sans-serif for supporting text. The typography should feel editorial, luxurious and timeless. Do NOT use overly decorative script fonts for important information. The names should always have enough width and spacing to display completely on mobile screens. OVERALL EXPERIENCE The website should feel like a cinematic journey: 1. Full-screen wedding video opening 2. Smooth transition from the video into the invitation 3. Hero / names 4. Wedding date 5. Countdown 6. Wedding details 7. Venue / location 8. Guest message section 9. Emotional cinematic ending The experience should be elegant, slow and immersive. Do not overload the page with animations. Use subtle transitions, gentle fades and very slow botanical movement. No flashy effects. No confetti. No excessive parallax. No generic wedding-template animations
